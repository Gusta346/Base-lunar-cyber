## Objetivo

A Central de Operações Lunar é uma aplicação desenvolvida em C# e .NET que simula o gerenciamento de uma base lunar. O operador acompanha ocorrências diárias, toma decisões para resolver problemas utilizando robôs especializados e monitora o estado geral da colônia.

O projeto foi desenvolvido com foco em Programação Orientada a Objetos, arquitetura em camadas e boas práticas de desenvolvimento.

## Módulo de Cibersegurança

Para atender aos requisitos de segurança do projeto, foi implementado um mecanismo de **backup automatizado** dos arquivos de histórico da operação.

O serviço de backup cria cópias de segurança dos registros gerados durante a execução do sistema, armazenando versões datadas em uma pasta específica. Dessa forma, caso ocorra perda ou corrupção de dados, as informações podem ser recuperadas rapidamente.

### Benefícios

* Preservação dos históricos operacionais.
* Maior disponibilidade das informações.
* Recuperação de dados em caso de falhas.
* Aplicação prática de um controle de segurança estudado na disciplina.
